# Fuentes anteriores

Conservadas para referencia y comparación. No se sirven desde la nueva aplicación.

- `original-public/`: frontend anterior de rifas.
- `original-server.js`: servidor anterior que escribía `data/db.json`.
- `original-reset-password.js`: script anterior, conserva una contraseña de ejemplo; no usarlo.
- `original-sorteo/`: copia del formulario de Apps Script, su script y logo.

La base JSON original no se mueve ni modifica. Para importarla usar la herramienta documentada en el README de la raíz. No ejecutar los servidores anteriores en paralelo con la aplicación nueva ni usar el script antiguo para cambiar credenciales.
